# پایش قیمت بازار — نمونه کار


ابزاری کوچک که قیمت چند ارز را بررسی می‌کند؛ وقتی قیمت از آستانه‌ی تعیین‌شده
عبور کند، هشدار چاپ می‌کند و یک گزارش تاریخچه‌ی قیمت هم به صورت یک فایل
مستقل می‌سازد.

**نکته‌ی مهم:** این نمونه هیچ سایتی را اسکرپ نمی‌کند و سراغ هیچ بازی یا بازاری
که شرایط استفاده‌اش اسکرپ را ممنوع کرده باشد نمی‌رود. منبع پیش‌فرض،
ای‌پی‌آی عمومی کوین‌گکو است (بدون کلید و بدون ثبت‌نام) و یک حالت نمایشی با
داده‌ی محلی هم دارد.

## این نمونه چه چیزی را نشان می‌دهد

- **دو حالت واقعی و نمایشی:** قیمت لحظه‌ای از ای‌پی‌آی عمومی خوانده می‌شود؛ حالت نمایشی با دادهٔ محلی و بدون اینترنت هم کار می‌کند.
- **هشدار آستانه:** برای هر ارز یک آستانهٔ جداگانه تعریف می‌شود و عبور از آن با پیام روشن گزارش می‌شود.
- **کد خروج معنادار:** اگر هشدار باشد کد خروج ۱ است، وگرنه ۰ — تا در اسکریپت‌ها و زمان‌بندی‌های دیگر قابل استفاده باشد.
- **پایش دوره‌ای:** با `--loop` هر چند ثانیه یک بار بررسی می‌کند و با `Ctrl+C` متوقف می‌شود.
- **گزارش تاریخچه‌ی قیمت:** یک فایل اچ‌تی‌ام‌ال مستقل می‌سازد؛ نمودار خطی میانگین و کمترین قیمت، جدول آمار با تاریخ هر عدد، کارت‌های مقایسه با میانگین و پنل تعیین قیمت دلخواه.
- **منبع قابل تعویض:** برای اتصال به منبع دیگر فقط یک تابع و یک فایل تنظیمات عوض می‌شود؛ بقیهٔ منطق دست نمی‌خورد.
- **بدون وابستگی خارجی:** فقط با کتابخانهٔ استاندارد پایتون نوشته شده و نصب اضافه‌ای نمی‌خواهد.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `monitor.py` | کد اصلی: گرفتن قیمت، مقایسه با آستانه، چاپ هشدار |
| `report.py` | ساخت گزارش اچ‌تی‌ام‌ال تاریخچه‌ی قیمت از داده‌ی نمایشی |
| `report.html` | گزارش ساخته‌شده (با اجرای `report.py` بازسازی می‌شود) |
| `config.json` | ارزها و آستانه‌ها (دلار) — همین فایل را ویرایش کنید |
| `demo_prices.json` | قیمت‌های نمایشی محلی برای تست بدون اینترنت |
| `demo_history.json` | تاریخچه‌ی نمایشی ۱۲۰ روزه‌ی قیمت‌ها (کمترین قیمت هر روز) |
| `sample_output.txt` | خروجی نمونه‌ی یک اجرا |
| `requirements.txt` | وابستگی ندارد؛ فقط کتابخانهٔ استاندارد پایتون کافی است |

## پیش‌نیازها

- پایتون ۳٫۹ یا بالاتر
- برای حالت واقعی: اینترنت (دسترسی به `api.coingecko.com`)
- برای حالت نمایشی و گزارش: هیچ چیز اضافه‌ای لازم نیست

## اجرا — قدم به قدم

### ۱. تست نمایشی (بدون اینترنت)

```bash
python3 monitor.py --demo
```

خروجی مورد انتظار (فایل `sample_output.txt` هم همین را نشان می‌دهد):
قیمت بیت‌کوین ۱۰۲٬۵۰۰ دلار است و از آستانه‌ی ۱۰۰٬۰۰۰ دلار عبور کرده، پس هشدار می‌دهد؛
اتریوم ۳٬۸۵۰ دلار است و زیر آستانه‌ی ۴٬۰۰۰ دلار می‌ماند.

### ۲. بررسی یک‌باره با قیمت واقعی

```bash
python3 monitor.py
```

اگر قیمت یک ارز از آستانه عبور کرده باشد، هشدار چاپ می‌شود و کد خروج `1` است؛
اگر هشداری نباشد کد خروج `0` است (برای استفاده در اسکریپت‌های دیگر مفید است).

### ۳. پایش دوره‌ای

```bash
python3 monitor.py --loop 60
```

هر ۶۰ ثانیه یک بار بررسی می‌کند. توقف با `Ctrl+C`.
برای اجرای دائمی روی سرور، از زمان‌بند خود سرور استفاده می‌شود.

### ۴. ساخت گزارش تاریخچه‌ی قیمت

```bash
python3 report.py
```

فایل `report.html` ساخته می‌شود؛ در مرورگر بازش کنید (اینترنت لازم نیست).
گزارش از داده‌ی نمایشی همین پوشه ساخته می‌شود و قیمت زنده نشان نمی‌دهد.

## گزارش تاریخچه‌ی قیمت چه دارد

- **نمودار تاریخچه:** دو خط روی یک نمودار — میانگین متحرک هفت‌روزه با خط سبز و کمترین قیمت هر روز با خط آبی. روزهایی که قیمت عوض نشده با خط‌چین خاکستری کشیده شده‌اند و در راهنمای نمودار هم با نماد خط‌چین «بدون تغییر» آمده‌اند. دکمه‌های بازه (۳۰ روز، ۹۰ روز، همه) نمودار را عوض می‌کنند.
- **جدول آمار:** برای هر ارز چهار عدد، هر کدام با تاریخش — کمترین قیمت، بیشترین قیمت، قیمت فعلی و میانگین ۱۲۰ روزه.
- **کارت‌های مقایسه با میانگین:** قیمت فعلی کنار میانگین، با درصد اختلاف؛ اگر قیمت فعلی زیر میانگین باشد برچسب «بهترین قیمت» می‌گیرد، وگرنه برچسب «بالای میانگین».
- **پنل تعیین قیمت دلخواه:** ارز و قیمت دلخواه را انتخاب می‌کنید؛ دکمه‌های میان‌بر (۳٪، ۵٪، ۷٪ و ۱۰٪ زیر قیمت فعلی، یا «هر کاهش قیمتی») قیمت را خودکار پر می‌کنند و با وارد کردن ایمیل، ثبت می‌شود. این پنل فقط نمایشی است: هیچ ایمیلی واقعاً فرستاده نمی‌شود و تایید ثبت فقط روی همان صفحه نشان داده می‌شود.
- **فایل مستقل:** همه‌ی سبک و نمودار و رفتار داخل خود فایل است؛ هیچ فایل یا سرویسی از بیرون خوانده نمی‌شود.

## تغییر آستانه‌ها و ارزها

فایل `config.json` را ویرایش کنید:

```json
{
  "coins": ["bitcoin", "ethereum"],
  "thresholds_usd": {
    "bitcoin": 100000,
    "ethereum": 4000
  }
}
```

- `coins`: شناسه‌ی ارزها در کوین‌گکو (مثلاً `bitcoin` ،`ethereum` ،`dogecoin`)
- `thresholds_usd`: آستانه‌ی هشدار به دلار برای هر ارز

## اتصال به یک منبع دیگر

برای اینکه اسکریپت به جای کوین‌گکو از منبع دیگری قیمت بگیرد، فقط این دو جا عوض می‌شود:

1. تابع `fetch_prices_live` در `monitor.py` — به جای فراخوانی کوین‌گکو،
   منبع جدید را بخواند و یک دیکشنری `{شناسه: قیمت}` برگرداند.
2. فایل `config.json` — شناسه‌ها و آستانه‌های منبع جدید را بگیرد.

بقیه‌ی منطق (مقایسه با آستانه و هشدار) بدون تغییر می‌ماند.
شرط ما: منبع جدید باید **ای‌پی‌آی عمومی یا داده‌ی مجاز** باشد، نه اسکرپ سایتی که
شرایط استفاده‌اش آن را ممنوع کرده است.

## بررسی سلامت کد

```bash
python3 -m py_compile monitor.py report.py
```
