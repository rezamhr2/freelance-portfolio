# درخت تصمیم با پانداس و سایکیت‌لرن — نمونه کار

> داده‌ها خیالی و ساخته‌ی دست هستند و فقط برای نمایش روش کارند.

یک مثال کوچک داده‌کاوی: با داده‌ی مشتریان (سن، تعداد بازدید ماهانه، میانگین مبلغ
سفارش) پیش‌بینی می‌کنیم مشتری اشتراک می‌خرد یا نه. مدل یک **درخت تصمیم**
(`DecisionTreeClassifier`) است؛ دقت و چند پیش‌بینی نمونه چاپ می‌شود.

## چرا این نمونه برای کارفرما جالب است

تقاضای زنده بازار برای همین نوع کار دیده می‌شود: در پونیشا یک کارفرما ۴۰ میلیون تومان
برای «اسکریپتی با پایتون که داده را از گوگل شیتز بخواند و تحلیل کند» پیشنهاد داده بود،
و در پارسکدرز هم پروژه‌های داشبورد داده و اتوماسیون با پایتون و شیتز دیده می‌شود.
این نمونه دقیقاً همان الگو را نشان می‌دهد — خواندن داده، تحلیل، و برگرداندن نتیجه
به‌صورت قابل فهم برای کارفرما — با این تفاوت که داده‌ها خیالی‌اند و فقط روش کار را
نمایش می‌دهند.

## این نمونه چه چیزی را نشان می‌دهد

- **مسیر کامل یک پروژهٔ داده‌کاوی کوچک:** خواندن داده، تقسیم به آموزش و تست، آموزش مدل، ارزیابی و پیش‌بینی — همه در یک اسکریپت خوانا.
- **ارزیابی صادقانه:** دقت روی دادهٔ تست (۲۵٪ داده‌ها که مدل آن‌ها را ندیده) گزارش می‌شود، نه روی دادهٔ آموزش.
- **قوانین قابل خواندن:** درخت به‌صورت متن چاپ می‌شود؛ در اجرای نمونه، قانون اصلی این است که مشتریانی با میانگین سفارش بالای ۱۶۵٬۰۰۰ تومان اشتراک می‌خرند و پایین‌تر از آن نه — یعنی نتیجه برای کارفرما قابل فهم و قابل استفاده است.
- **آمادهٔ دادهٔ واقعی:** کافی است فایل داده را با دادهٔ کارفرما عوض کنید؛ نام ستون‌ها همان‌ها بمانند، بقیهٔ کد بدون تغییر کار می‌کند.
- **پیش‌بینی نمونه:** سه مشتری نمونه با مشخصات مختلف پیش‌بینی می‌شوند تا خروجی مدل ملموس باشد.

## فایل‌ها

| فایل | توضیح |
|---|---|
| `train_tree.py` | کد اصلی: خواندن داده، آموزش مدل، چاپ دقت و پیش‌بینی |
| `customers.csv` | داده‌ی نمونه‌ی خیالی — ۴۰ مشتری (سن، بازدید ماهانه، مبلغ سفارش، وضعیت اشتراک) |
| `requirements.txt` | وابستگی‌ها (`pandas` و `scikit-learn`) |

## پیش‌نیازها

- پایتون ۳٫۹ یا بالاتر
- نصب وابستگی‌ها (یک بار):

```bash
pip install -r requirements.txt
```

## اجرا — قدم به قدم

```bash
python3 train_tree.py
```

خروجی شامل این‌هاست:

1. تعداد ردیف‌ها و آمار توصیفی داده
2. **دقت** مدل روی داده‌ی تست (۲۵٪ داده‌ها، جدا شده با `random_state=42`)
3. گزارش طبقه‌بندی (دقت، بازیابی و امتیاز اف‌یک)
4. قوانین درخت به صورت متن (کدام ویژگی، کجا شاخه می‌شود)
5. پیش‌بینی سه مشتری نمونه

## تغییر داده یا مدل

- **داده‌ی خودتان:** فایل `customers.csv` را با داده‌ی واقعی عوض کنید؛
  فقط نام ستون‌ها (`age` ،`monthly_visits` ،`avg_order_toman` ،`subscribed`)
  باید همین‌ها بمانند، یا لیست `features` در `train_tree.py` را مطابق آن عوض کنید.
- **عمق درخت:** پارامتر `max_depth=3` در `train_tree.py` را تغییر بدهید؛
  عمق بیشتر = درخت پیچیده‌تر و ریسک بیشترِ بیش‌برازش.
- **مدل دیگر:** به جای `DecisionTreeClassifier` می‌شود مدل دیگری از
  `scikit-learn` گذاشت؛ بقیه‌ی کد (تقسیم داده و ارزیابی) بدون تغییر می‌ماند.
